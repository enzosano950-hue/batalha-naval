
# Batalha Naval

## Sobre o Projeto

Este projeto é uma implementação completa do clássico jogo **Batalha Naval**, desenvolvida utilizando **HTML, CSS e JavaScript puro**, com foco na aplicação prática de lógica de programação, manipulação do DOM, organização de código e desenvolvimento de interfaces web.

O jogo oferece diferentes modos de jogo, níveis de dificuldade e uma inteligência artificial capaz de enfrentar o jogador em partidas individuais, proporcionando uma experiência dinâmica e interativa.

Durante o desenvolvimento, foram aplicados conceitos importantes como gerenciamento de estado da aplicação, geração aleatória de elementos, manipulação do armazenamento local (LocalStorage), modularização do código e criação de interfaces responsivas.

##  Inteligência Artificial(Maquina)

Um dos principais diferenciais deste projeto é a implementação de uma IA para o modo jogador contra computador.

Cada nível de dificuldade altera o comportamento da máquina:

### Fácil

* Tabuleiro menor.
* IA realiza jogadas totalmente aleatórias.
* Maior quantidade de barcos.

### Normal

* Tabuleiro maior.
* IA continua realizando jogadas aleatórias.
* Distribuição equilibrada entre barcos e bombas.

### Difícil

* IA otimizada.
* Após encontrar um barco, passa a priorizar posições estratégicas próximas.
* Tempo de resposta reduzido.
* Maior desafio para o jogador.

##  Objetivo

O principal objetivo deste projeto foi desenvolver uma aplicação completa utilizando apenas tecnologias fundamentais da web, sem o uso de frameworks, fortalecendo meus conhecimentos em lógica de programação, desenvolvimento front-end e organização de projetos.
